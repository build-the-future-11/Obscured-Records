# Distribution rules for clusters

For every cluster:

- one pillar/flagship role;
- 3–8 supporting records;
- one explicit reporting-gap list;
- intentional two-way internal links;
- a review/update date;
- search/query hypotheses recorded before performance review;
- distribution partners selected by actual topical fit;
- no draft promoted publicly until it clears editorial review.

# First implementation order

1. Software, interfaces and hidden assumptions.
2. Corporate controls, accounting and institutional trust.
3. Environmental contamination and exposure pathways.
4. Warning, anomaly and decision systems.

These four have enough current archive/draft density to test the cluster model without manufacturing new articles solely to fill a taxonomy.
